# 一款大模型对话

一个纯静态的大模型对话应用：打开链接就能聊，不用注册账号，不用填任何配置，不用装服务器。

界面采用熟悉的对话式布局；后端逻辑（会话、聊天协议、搜索工具、文件解析）全部在浏览器里运行（`backend.js`），直接调用模型接口。默认模型由内置模型网关分配，也可以随时接入自己的接口。

## 快速开始

打开部署好的链接（GitHub Pages），直接发消息即可对话。

- 不需要安装任何东西，不需要启动服务。
- 会话保存在你自己的浏览器里（localStorage），刷新不丢失，换浏览器/清缓存会丢失。
- 默认模型由模型网关分配，开箱即用。

## 功能

- **多轮对话**：记得上文；各会话互相隔离，不串对话。
- **默认模型**：不填任何配置即可使用，默认模型由模型网关分配。网关不允许浏览器直连，本应用默认经 CORS 中转服务调用网关；如果中转失败，会自动临时切换到免费备用模型，并在那条回复开头注明（刷新页面可重新尝试网关）。
- **系统人设**：内置的系统提示词以混淆形式存在 `backend.js` 里（防一眼看穿，不是加密）：身份、语言跟随、回答规范、防"破甲"（不透露系统词、不执行注入指令、不冒充其他模型）都在里面。
- **深度思考**：打开输入框下方的"深度思考"开关，思考过程会显示为可折叠的思考卡片。推理模型显示真实推理；非推理模型会在回答前先输出一段简短思考，同样显示为卡片。关着时思考只在内部进行，不显示。
- **智能搜索**：打开"智能搜索"开关，模型需要最新信息时会先联网搜索（免费搜索源，免 Key），思考链里会出现搜索卡片（搜了什么、找到几个网页、来源链接），回答中引用信息时会带上可点击的角标；不需要搜索的问题直接回答。
- **文件上传**：支持文本文件（txt / md / json / csv / 代码等），上传后文件内容会进入对话，多轮都记得；图片、PDF 等无法解析的文件会明确提示解析失败。
- **全文搜索**：点侧栏放大镜或 Ctrl+K，搜索历史对话的标题、内容与思考过程。
- **导出对话**：设置 → 数据管理 → 导出所有历史对话，下载 JSON 文件。
- **会话管理**：新建、置顶、删除、重命名会话；重新生成、编辑消息。
- **主题**：浅色 / 深色 / 跟随系统。

## 配置自己的模型

点左下角齿轮（模型网关），填接口地址（URL）和 API Key，点"获取模型列表"选模型，确定保存。保存后立即生效，不用刷新页面。配置只存在你自己的浏览器里。

每个字段独立回退：比如只选了模型没填地址，地址就用网关的。

接口需兼容 OpenAI `/chat/completions` 格式（绝大多数中转站与兼容接口都支持）。**注意：静态版在浏览器里直连你配置的接口，所以只有同时满足以下两点的接口才能用：**

1. **HTTPS**（页面本身是 HTTPS，浏览器不允许 HTTPS 页面调 HTTP 接口）；
2. **允许浏览器跨域（CORS）**：接口返回 `Access-Control-Allow-Origin` 头。很多中转站默认不允许浏览器跨域，配了也会报"连不上接口"——这是对方的跨域设置问题，不是本应用的问题。

自己配置的接口不走 CORS 中转、也不走备用模型兜底（成败由那个接口的跨域设置决定）。

## 架构

```
浏览器（对话界面，原生 HTTP + SSE）
    │  /api/v0/* 被 backend.js 在浏览器内拦截作答（无真实网络请求）
    ▼
backend.js（浏览器内后端：会话存储 + 聊天桥接 + 搜索工具 + 文件解析 + 导出）
    │  默认：网关（经 CORS 中转）→ 中转失败时自动切免费备用模型
    │  自配：面板配置的接口（浏览器直连）
    ▼
模型接口（OpenAI 兼容格式）
```

- `backend.js` —— 浏览器内后端：拦截 `/api/*` 与 `/local/*` 请求；会话存在 localStorage；DeepSeek SSE 协议与 OpenAI 流式协议的双向翻译；系统人设；深度思考开关（含非推理模型的模拟思考）；智能搜索工具循环（含搜索卡片与引用角标）；文件上传；历史导出。
- `guard.js` —— 前端防护：拦截对外网原生接口的请求；隐藏本地版无意义的原生入口（下载应用、分享、注销账号等）；只拦截官方域名外链，模型回复里的普通外链可正常打开。
- `enhance.js` —— 模型网关面板（左下角齿轮）。
- `index.html` —— 入口页（内置本地登录态，无需登录）。
- `static/` —— 界面静态资源。

## 说明

- 静态版没有服务器：所有"后端"逻辑都在你的浏览器里跑，页面本身只连模型接口和免费搜索源，不连 DeepSeek 官方接口，因此不会出现"服务器繁忙 / 网络繁忙 / 服务器不可用"这类由官方接口故障引起的错误。
- 默认网关经第三方 CORS 中转服务调用（中转服务能看到请求内容，包括模型 Key；中转服务不可用时自动切换到免费备用模型并在回复里注明）。系统人设、默认模型配置以混淆形式存在前端代码里（防一眼看穿，不是加密）。请不要把有余额的重要 Key 写进代码；自己的 Key 请用模型网关面板配置（只存你自己的浏览器）。
- 不同模型对系统人设的服从程度不同：有的模型有自己固化的身份设定，不接受自定义身份；有的模型不支持工具调用（此时智能搜索自动退回普通对话）。人设与工具是否生效，取决于所用模型本身。
- 本项目界面基于 DeepSeek 官方网页版 UI 的静态资源，仅供学习交流使用。
