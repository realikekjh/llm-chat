=== 一款大模型对话 · 静态版（V4.2，GitHub Pages） ===

打开部署好的链接就能聊，不用装服务器、不用启动任何东西。
打开就是已登录，直接发消息即可对话，不用填任何东西。
默认模型由模型网关分配。

默认模型怎么工作：
  - 网关不允许浏览器直连，所以默认请求经 CORS 中转服务调用网关。
  - 如果中转失败（中转服务挂了、被拦了），同一条请求会自动改用
    免费备用模型重试，并在那条回复开头注明"已临时切换到免费备用模型"。
    之后本页内不再重试网关（避免每条消息都卡一次），刷新页面可重新
    尝试网关。

配置模型（点左下角齿轮 → 模型网关）：
  - 填接口地址（URL）+ API Key → 获取模型列表 → 点选一个模型 → 确定保存。
    保存后立即生效，不用刷新页面。只选模型不填 URL/Key 也行，URL/Key 用网关的。
  - 自己配的接口是浏览器直连的，必须同时满足：①HTTPS；②对方允许浏览器
    跨域（CORS）。很多中转站默认不允许浏览器跨域，配了也会报"连不上接口"，
    那是对方的跨域设置问题。自配接口不走中转、也不走备用模型兜底。

两个开关（输入框下方）：
  - 深度思考：打开后，推理模型的思考过程会显示为可折叠的"已思考"卡片；
    关着时思考只在内部进行，不显示。默认关着。
  - 智能搜索：打开后，模型需要最新信息时会先联网搜索（免费搜索源，
    不用另外配 Key），再根据搜索结果回答并注明来源；不需要搜索的问题
    直接回答。默认关着。

文件上传（输入框右侧回形针）：
  - 文本文件（txt / md / json / csv / 代码等）上传后内容会拼进对话，
    多轮都记得；刷新后内容还在历史里。
  - 图片、PDF 等解析不了的文件会显示解析失败，不会假装模型看到了。
  - 单文件上限 10MB，文本最多取前 100KB。

会话存在你自己的浏览器里（localStorage），刷新不丢；
换浏览器或清缓存会丢失。导出：设置 → 数据管理 → 导出所有历史对话。

这个包里已经没有官方原生东西：
  - 所有 /api 请求都在浏览器内由 backend.js 作答，不连 DeepSeek 官方接口，
    不会出现"服务器繁忙 / 网络繁忙 / 服务器不可用"。
  - 下载应用、分享、帮助与反馈、退出登录已从界面上删掉；
    设置页里本地版无意义的项（注销账号、登出所有设备、登录设备管理、
    数据用于优化体验、我共享的链接、服务协议）也已藏掉。
  - 火山引擎上报、数美风控、微信/苹果登录 SDK 已移除/拦截。
  - PoW 已本地短路 + 真可解挑战，发消息不会卡在验证上。
  - 模型回复里的外链（非 DeepSeek 官方域名）可以正常点开。

已实现的功能：
  - 深度思考卡片：开关打开且模型有思考时显示，刷新后还在。
  - 智能搜索卡片：搜索时思考链里出现搜索卡片，回答带可点击的来源角标。
  - 侧栏搜索按钮：点放大镜或 Ctrl+K，全文搜索历史对话（标题、内容、思考）。
  - 多轮对话：记得上文；各会话互相隔离，不串对话。
  - 空会话不进侧栏：预创建的"新对话"只有发了消息才会留下。
  - 删除/置顶/重命名会话、重新生成、编辑消息，均可用。

注意：
  - 默认网关经第三方 CORS 中转服务调用，中转服务能看到请求内容；
    不要把有余额的重要 Key 写进代码里；自己的 Key 请用齿轮面板配。
  - 系统人设、默认模型配置是混淆存储的（防一眼看穿，不是加密）。
  - 朗读（TTS）还没接。
