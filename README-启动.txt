=== 一款大模型对话 · 本地版（V4） ===

启动（在本目录下）：
  python3 serve.py 8796
  或双击 start.sh（Linux / Mac）

打开浏览器：
  http://127.0.0.1:8796/
  打开就是已登录，直接发消息即可对话，不用填任何东西。
  默认模型由模型网关分配。

配置模型（三级，前面优先；每个字段独立回退）：
  A. 点左下角齿轮（模型网关）→ 填接口地址（URL）+ API Key →
     获取模型列表 → 点选一个模型 → 确定保存。保存后立即生效，不用刷新页面。
     只选模型不填 URL/Key 也行，URL/Key 用网关的。
  B. 复制 local-config.example.json 为 local-config.json 后填写
     （url / key / model），改完不用重启服务。
  C. 都不填：用内置模型网关的默认模型。

两个开关（输入框下方）：
  - 深度思考：打开后，推理模型的思考过程会显示为可折叠的"已思考"卡片；
    关着时思考只在内部进行，不显示。默认关着。
  - 智能搜索：打开后，模型需要最新信息时会先联网搜索（免费 DuckDuckGo，
    不用另外配 Key），再根据搜索结果回答并注明来源；不需要搜索的问题
    直接回答。默认关着。

文件上传（输入框右侧回形针）：
  - 文本文件（txt / md / json / csv / 代码等）上传后内容会拼进对话，
    多轮都记得；刷新后内容还在历史里。
  - 图片、PDF 等解析不了的文件会显示解析失败，不会假装模型看到了。
  - 单文件上限 10MB，文本最多取前 100KB。

这个包里已经没有官方原生东西：
  - 所有 /api 请求都只到本机 serve.py，不连 DeepSeek 官方接口，
    不会出现"服务器繁忙 / 网络繁忙 / 服务器不可用"。
  - 下载应用、分享、帮助与反馈、退出登录已从界面上删掉；
    设置页里本地版无意义的项（注销账号、登出所有设备、登录设备管理、
    数据用于优化体验、我共享的链接、服务协议）也已藏掉。
  - 火山引擎上报、数美风控、微信/苹果登录 SDK 已移除/拦截。
  - PoW 已本地短路 + 真可解挑战，发消息不会卡在验证上。
  - 模型回复里的外链（非 DeepSeek 官方域名）可以正常点开。

已恢复 / 已实现的功能：
  - 深度思考卡片：开关打开且模型有思考时显示，刷新后还在。
  - 侧栏搜索按钮：点放大镜或 Ctrl+K，全文搜索历史对话（标题、内容、思考）。
  - 多轮对话：记得上文；会话存在 sessions.json，刷新不丢；各会话互相隔离。
  - 空会话不进侧栏：预创建的"新对话"只有发了消息才会留下。
  - 导出所有历史对话：设置 → 数据管理 → 导出，下载 JSON 文件。
  - 删除/置顶/重命名会话、重新生成、编辑消息，均可用。

注意：
  - 如果你填了自己的 Key（面板或 local-config.json），不要把整个包发给别人。
  - 朗读（TTS）还没接。
  - 内置模型网关的配置是混淆存储的（防一眼看穿，不是加密），不要把有余额的
    重要 Key 写进代码里；自己的 Key 请用面板或 local-config.json 配。
